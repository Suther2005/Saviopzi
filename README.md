# SAVIOPZI

**Learn. Practice. Build. Grow.**

An AI-Powered E-Learning Platform built as a portfolio project.

## Overview
SAVIOPZI is a modern learning platform where students can enroll in courses, track progress, take quizzes, and interact with an AI Learning Assistant. Instructors can manage their courses, and Admins can oversee the platform.

## Features
- Role-based Authentication (Student, Instructor, Admin)
- Course Discovery & Enrollment
- Learning Progress Tracking
- Interactive Quizzes
- SAVIOPZI AI Learning Assistant (Ask, Summarize, Generate Quiz)
- Certificates of Completion

## Tech Stack
- **Frontend**: React, HTML, CSS (Vite)
- **Backend**: Java, Spring Boot, Spring Security (JWT)
- **Database**: MySQL (JPA/Hibernate)

## Architecture
Standard 3-tier architecture with a React SPA frontend, a Spring Boot REST API backend, and a MySQL relational database.
